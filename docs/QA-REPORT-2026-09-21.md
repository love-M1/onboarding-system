# 真实流程检查与修复记录

执行日期：2026-09-21

## 检查范围

- 后端自动化测试与前端生产构建。
- HR 登录、模板维护、员工建档、员工注册、任务确认、进度汇总和归档闭环。
- 桌面端与 375px 移动端浏览器交互。
- 浏览器控制台错误、页面运行时异常和失败请求。

## 发现的问题

### 1. 正常操作产生未处理异常

表单校验失败、确认框取消和后端业务拒绝都会让异步事件处理器返回 rejected Promise，表现为 Vue `Unhandled error` 或浏览器 `pageerror`。

复现场景：

- 新增档案或模板时留空提交。
- 取消归档或任务确认。
- 归档仍有未完成任务的档案，后端返回业务错误。

### 2. 移动端任务关键信息不可见

375px 宽度下，任务表首屏只显示任务编号、名称和操作。责任部门、应完成日期和状态需要横向滑动表格才能看到。

### 3. 入职日期显示后端原始时间

档案列表、归档列表和档案详情直接显示 `2026-09-21T00:00:00`，与纯日期录入方式和页面语义不一致。

## 修改内容

- 新增表单校验和确认框状态处理，避免正常取消与校验失败进入全局异常链路。
- 所有页面级接口调用统一吸收已由 HTTP 拦截器展示的错误，不再重复抛出运行时异常。
- 375px 及以下使用移动任务卡片，优先展示状态、责任部门、应完成日期和操作。
- 新增日期格式化工具，统一展示为 `YYYY-MM-DD`。
- 新增 Node 测试，覆盖校验失败、确认取消、意外确认错误和日期格式化。
